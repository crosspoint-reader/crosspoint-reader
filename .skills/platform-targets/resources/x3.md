# Xteink X3

ESP32-C3, no PSRAM. 792×528 panel; UC8253 or UC8279d (`XTEINK_X3_UC8279`) on
newer glass. Same pinout as X4. BQ27220 gauge, DS3231 RTC, QMI8658 IMU. No
touch, no frontlight.

Shares one C3 binary with X4 via `[env:default]` and the C3 release aliases.
Runtime pick is `selectDevice` / `XteinkDetect`. This profile is the larger
framebuffer (52,272 bytes), so it sizes `MAX_FRAMEBUFFER_BYTES` for that
binary. This file stays `x3.md` if `default` is later split into its own env.
