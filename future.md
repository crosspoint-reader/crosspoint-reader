## 3. Крупные фичи (выбрать одну следующей «большой» фазой)

- [ ] **Статистика чтения** 🥇 — самая ожидаемая. Референсы: CrossInk
  («минимальная»: книги/время/сессии/страницы, отключение per-book) и
  Witchhunt (богатая: стрики, история per-book «Read 3h 18m over 5 days»,
  графики по времени суток). Фундамент в прошивке уже есть: `ReaderSession`
  (src/activities/reader/ReaderSession) пишет сессии для плагин-событий —
  останется персистентный стор + экран(ы). Влезает в ~25% свободного flash.
- [ ] **Per-book настройки** (шрифт/размер/поля на книгу) — референс
  CrossInk (v1.3.4). Аккуратно с вёрсткой: сигнатура рендера
  (`readerRenderSpecSignature`) уже учитывает всё нужное — расширить на
  per-book источник.
- [ ] **Поиск по книге** — референсы inkMOD и Witchhunt. Механика:
  `getTextFromSectionFile` по секциям + UI навигации по результатам.

## 4. Опционально / «на аппетит»

- [ ] **Markdown как формат книг** — конвейер по лекалам FB2 (даже проще:
  md → HTML → синтетический EPUB). Референс: Witchhunt (2.41 рендерит
  pipe-таблицы сеткой).
- [ ] **Web-интерфейс на SD** — обновление веб-морды без перепрошивки

  часовых пересборках.
- [ ] **Inline-раскрытие сносок** прямо в тексте страницы (референс
  Witchhunt) — альтернатива попапам, сложнее в вёрстке.
- [ ] **Погодная панель** на home (Open-Meteo, без ключей; Witchhunt).
- [ ] **Jump-to-printed-page** — печатная пагинация из EPUB
  (референсы: CrossInk v1.3.1 «publisher page numbers», Witchhunt
