Pocket Library

Wikipedia, entire and offline, in a reader that fits in your hand.

With pictures, a dictionary, travel guides and first aid. No signal required.

You need

Xteink X4 Pro$99

The Pro. Other Xteink models won't work.

256 GB microSD cardabout $25

A name brand, such as Samsung PRO Plus or SanDisk Extreme.

And a Mac, with the USB-C cable that charges it.

Steps

  1. Install Python

    Download the macOS installer from python.org and run it.

  2. Install CrossPoint

    Connect the reader with its magnetic adapter and wake it. Open Terminal and run this to back it up:

    mkdir -p ~/PocketLib && cd ~/PocketLib && curl -fsSLO https://github.com/noah-pi/pocket-library/releases/download/dev/flash.sh && bash flash.sh backup

    Then, in Chrome, open crosspointreader.com → Flash tools → Xteink X4 Pro, and install.

  3. Install Pocket Library

    cd ~/PocketLib && bash flash.sh

    The reader restarts when it's done.

  4. Format the card

    In Disk Utility, choose View → Show All Devices, select the card, and click Erase.

    Name POCKETLIB · Format ExFAT · Scheme Master Boot Record

  5. Fill the card

    cd ~/PocketLib && curl -fsSLO https://github.com/noah-pi/pocket-library/releases/download/dev/get-tools.sh && bash get-tools.sh
    cd ~/PocketLib/cardbuilder && caffeinate -i python3 cardbuilder.py all --card /Volumes/POCKETLIB --verify

    This takes several hours. Leave it overnight. If it stops, run it again; it picks up where it left off.

  6. Insert the card

    Eject it, put it in the reader, and open Library.

If something fails

Reader not found. Press its power button and run the command again.

Python too old. Open a new Terminal window after installing Python.

To undo. bash flash.sh restore returns the reader to how it came.

Anything else. Open an issue.
