# Translators

Below is a list of the people who have contributed translations. The languages
the firmware ships are the files in `lib/I18n/translations/`; see [i18n.md](i18n.md)
for how they are built.

Most of these translations were written for
[crosspoint-reader](https://github.com/crosspoint-reader/crosspoint-reader), which this firmware
is a fork of. Since 2.40 we take crosspoint-reader's wording wherever its translators have
translated the same English text, so the people below wrote the strings you see. Their
translation PRs were collected into crosspoint-reader by Uri Tauber
([Uri-Tauber](https://github.com/Uri-Tauber)) in #2740, #2946 and #3396.

Strings that exist only in this firmware (the Library, Diagnostics, plugins and others) were
machine-translated in 2.40 and have not been reviewed by native speakers yet. Corrections are
welcome.
